# Modernized RPI Robotics Website

<a href="https://sites.ecse.rpi.edu/roboticsclub/">
<img width="2605" height="1539" alt="image" src="https://github.com/user-attachments/assets/4de92a11-fc53-4c3a-9f8b-48a0b3482592" />
</a>

Developed Fall 2025 to provide up-to-date information about RPI Robotics club operations.
Features a dynamic homepage displaying a rotating selection of recent posters.
Projects summaries are displayed in rich cards, allowing prospective members to glean over the club's offerings and choose teams that interest them.
Executive board and team leads directory allows quick contact of important members.
The club's official Google Calendar is easily accessible, inviting members to fill open time with club activities.

React SPA framework structured for reusable components and customizable look-and-feel. loads entire site content in one object.
Hosted on RPI hardware and bootstrapped via FTP.
Entire site content loaded in one JS object; either from local file, or retrieved from a remote JSON source via `fetch`.
